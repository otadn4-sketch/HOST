# مدل تهدید

## دارایی‌ها

حساب‌ها، نشست‌ها، فایل‌های سازمانی، هش و متادیتا، لاگ ممیزی، کلید امضای انتشار، کلید بکاپ، TLS.

## مهاجمان

کاربر داخلی کنجکاو، کاربر با نقش پایین‌تر، بارگذاری فایل مخرب، ناظر شبکه، مهاجم با ZIP به‌روزرسانی جعلی.

## سوءاستفاده‌های پوشش‌داده‌شده

| سناریو | کنترل |
| --- | --- |
| Brute force | rate limit + قفل حساب + پیام ورود یکسان |
| سرقت JWT از localStorage | JWT نیست؛ کوکی HttpOnly |
| CSRF | توکن هم‌خوان با نشست |
| IDOR | 404 یکسان برای عدم دسترسی |
| Path traversal / zip bomb / symlink در آپلود و بسته به‌روزرسانی | اعتبارسنجی |
| اجرای فایل بارگذاری‌شده | خارج از web root، بدون اجرا، مسدودسازی اجرایی |
| بدافزار | ClamAV fail-closed؛ فایل بدون پویش امن تلقی نمی‌شود |
| جعل بسته به‌روزرسانی | Ed25519 + hash list + manifest اجباری در production |
| افشای مسیر دیسک | حذف از API |
| ویرایش لاگ | listener منع update/delete |
| ارسال پیامک ناخواسته | `SMS_ENABLED` پیش‌فرض false؛ در production قفل |
| گراف تعاملات روی وب عمومی | فقط localhost؛ پرچم فاز ۵ پیش‌فرض خاموش |

## موارد باقی‌مانده وابسته به بهره‌برداری

سخت‌سازی OS سرور، جداسازی دیسک بکاپ، فرآیند واکنش انسانی، بازبینی دوره‌ای دسترسی‌ها (T-030 عملیاتی).
