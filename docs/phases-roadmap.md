# نقشه راه پنج‌فاز سامانه ایتان

سامانه از «ارسال خودکار فایل/لینک» به «بایگانی و ثبت دستی تعامل» منتقل شده است. ارسال از طریق پیام‌رسان یا پیامک در production تا تصمیم کتبی جدید خاموش است.

## فاز ۱ — بایگانی و ثبت دستی (فعال)

- مخزن فایل موجود حفظ شده است.
- ثبت دستی: کدام فایل، به چه کسی، در چه تاریخی، برای چه هدفی، از چه کانالی، با چه یادداشتی.
- کانال‌های خودکار (SMS، Telegram، WhatsApp، ارسال خودکار) در اعتبارسنجی رد می‌شوند.
- جست‌وجو و پالایش روی مخاطب، فایل، تاریخ، هدف و کانال.

## فاز ۲ — ثبت جلسات و ارائه‌ها (فعال با پرچم)

فرم و API برای جلسه حضوری و ارائه بیرونی به‌عنوان تراکنش تعامل.

## فاز ۳ — پروفایل مخاطبان بیرونی (فعال با پرچم)

تاریخچه تعامل، گزارش‌های تحویل‌شده و منشأ درخواست.

## فاز ۴ — اشتراک‌گذاری درون‌شبکه‌ای (خاموش تا فعال‌سازی پرچم)

اشتراک فقط برای کاربر مشخص داخل سامانه است. لینک عمومی یا دسترسی ناشناس ساخته نمی‌شود. انقضا، لغو، ممیزی و محدودیت نقش اعمال می‌شود. دریافت از مسیر اشتراک دوباره پویش و مجوز فایل را کنترل می‌کند. اگر فاز خاموش باشد API با ۴۰۳ پاسخ می‌دهد.

## فاز ۵ — امنیت، پالایش سند و گراف محلی

- پالایش متن و DOCX واقعی است و نسخهٔ جدا می‌سازد؛ فایل اصلی تغییر نمی‌کند.
- PDF و قالب‌های دیگر fail-safe هستند (`publication_ready=false`) و امن/آمادهٔ انتشار تلقی نمی‌شوند.
- گراف فقط برای مدیر سامانه، فقط با پرچم فاز ۵، و نه در production. کنترل localhost به هدر Host اکتفا نمی‌کند.

## اتصال فاران

کلاینت ماژولار `app/services/faran.py` متادیتای فایل را برای همگام‌سازی آماده می‌کند. به‌صورت پیش‌فرض هیچ درخواست شبکه‌ای ارسال نمی‌شود (`FARAN_ENABLED=false`, `FARAN_ALLOW_NETWORK=false`).
