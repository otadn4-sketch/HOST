# نقشه راه پنج‌فاز سامانه ایتان

سامانه از «ارسال خودکار فایل/لینک» به «بایگانی و ثبت دستی تعامل» منتقل شده است. ارسال از طریق پیام‌رسان یا پیامک در کد منسوخ و به‌صورت دائمی خاموش است.

## فاز ۱ — بایگانی و ثبت دستی (فعال)

- مخزن فایل موجود حفظ شده است.
- ثبت دستی: کدام فایل، به چه کسی، در چه تاریخی، برای چه هدفی.
- جست‌وجو و پالایش روی مخاطب، فایل، تاریخ و هدف.

## فاز ۲ — ثبت جلسات و ارائه‌ها (فعال با پرچم)

فرم و API برای جلسه حضوری و ارائه بیرونی به‌عنوان تراکنش تعامل.

## فاز ۳ — پروفایل مخاطبان بیرونی (فعال با پرچم)

تاریخچه تعامل، گزارش‌های تحویل‌شده و منشأ درخواست.

## فاز ۴ — اشتراک‌گذاری امن و RBAC دانه‌ای (خاموش)

اسکلت API و UI موجود است؛ ایجاد پیوند عمومی تا تکمیل کنترل دسترسی فعال نمی‌شود.

## فاز ۵ — امنیت، پالایش سند و گراف محلی (خاموش)

- آمادگی آزمون نفوذ روی استک فعلی.
- خط لوله stub برای پالایش PDF/Word.
- گراف تعاملات فقط روی `localhost` و خارج از وب عمومی.

## اتصال فاران

کلاینت ماژولار `app/services/faran.py` متادیتای فایل (برچسب، پدیدآورنده، داده اکسل) را برای همگام‌سازی آماده می‌کند. به‌صورت پیش‌فرض هیچ درخواست شبکه‌ای ارسال نمی‌شود (`FARAN_ENABLED=false`, `FARAN_ALLOW_NETWORK=false`).
