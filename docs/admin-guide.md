# راهنمای مدیر سامانه

## ورود

با نام کاربری و گذرواژه‌ای که از `create-admin` یا پنل کاربران ساخته شده وارد شوید. نقش از UI قابل تغییر نیست. نام کاربری لاتین است و حروف بزرگ/کوچک یکی گرفته می‌شوند.

اگر حساب قفل شده، چند دقیقه صبر کنید یا از مدیر دیگری unlock بگیرید. اگر هیچ مدیری در دسترس نیست و تصمیم به پاک‌کردن تمام داده است: `docs/deployment-guide.md` بخش «ریست کامل داده» و سپس `./scripts/create-admin.sh`. گذرواژهٔ مدیر حداقل ۱۲ نویسه با حرف بزرگ، حرف کوچک، رقم و نویسه ویژه است.

## کاربران و گروه‌ها

منوی «مدیریت کاربران و گروه‌ها»: ایجاد، تعلیق، بازنشانی گذرواژه. مدیر گروه فقط اعضای گروه خود را می‌بیند.

## بازیابی دسترسی

کاربر از صفحه ورود درخواست می‌دهد. مدیر از API/فرایند برون‌خط توکن یک‌بارمصرف صادر می‌کند (`POST /api/users/{id}/recovery-token`). توکن را از کانال امن به کاربر بدهید.

## فایل‌ها

بارگذاری پس از پویش. فایل قرنطینه‌شده قابل دریافت نیست. نسخه‌های جدید از همان فرم با `parent_file_id` ثبت می‌شوند.

## سیاست

تنظیمات ← سیاست‌های امنیتی: فرمت، سقف حجم، مدت نشست، تعداد شکست ورود. مسیر دیسک از UI ویرایش نمی‌شود. HTTPS روی ۴۴۳ فعال است؛ پورت ۸۰ برای تونل موقت و دسترسی HTTP محلی هم سامانه را سرو می‌کند.

## پیش‌نمایش آفیس و وب‌اپ

پیش‌نمایش ورد/اکسل/پاورپوینت متن فایل را نشان می‌دهد. روی موبایل می‌توان سامانه را با «افزودن به صفحه اصلی» مثل اپ نصب کرد.

## به‌روزرسانی

تنظیمات ← به‌روزرسانی سامانه: فقط بسته امضاشده با manifest، فهرست hash و امضای Ed25519. بسته بدون امضا یا بدون `UPDATE_PUBLIC_KEY` رد می‌شود.

## پیامک

ارسال پیامک در production غیرفعال است. برای ثبت تحویل از «ثبت دستی تحویل» استفاده کنید.

## لاگ

لاگ‌ها فقط خواندنی‌اند. رخدادهای ورود، مشاهده، دریافت، بارگذاری، قرنطینه، تغییر مجوز و به‌روزرسانی ثبت می‌شوند.

## خطایابی پایه

- ورود ناموفق مکرر: قفل موقت؛ مدیر unlock کند
- آپلود رد می‌شود: فرمت/حجم/ClamAV
- داشبورد دیده نمی‌شود: فقط مدیر سامانه
